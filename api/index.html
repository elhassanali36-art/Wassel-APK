١) فحص الاتصال

curl "https://base44.app/api/apps/6a74dc8dc6a9c9d7bc3ef6d1/functions/wasselApi?action=ping"

٢) نشر طلب

curl -X POST "https://base44.app/api/apps/6a74dc8dc6a9c9d7bc3ef6d1/functions/wasselApi?action=publish" \
  -H "content-type: application/json" \
  -H "x-store-key: مفتاح_متجرك" \
  -d '{
    "external_id": "ORD-1042",
    "drop_lat": 15.5512,
    "drop_lng": 32.6145,
    "drop_label": "الطائف - شارع 15",
    "items_summary": "سلة خضار + أرز 5ك",
    "customer_name": "سارة عثمان",
    "customer_phone": "0922334455"
  }'
الحقلإلزاميالمعنى
external_idنعمرقم الطلب في منصتك. نفس الرقم لا يُنشئ نسخة ثانية
drop_lat / drop_lngنعمإحداثيات عنوان التسليم
drop_labelلاوصف العنوان كما يظهر للسائق
pickup_lat / pickup_lngلاإن لم تُرسل تُستخدم إحداثيات المتجر المسجّلة
items_summaryلاملخص الطلب
customer_name / customer_phoneلابيانات العميل
delivery_feeلاإن أرسلتها تُستخدم بدل حساب المسافة
الرد: {"ok":true,"order_id":"…","status":"POOL","fee_sdg":38325,"distance_km":10.95,"duplicate":false}

٣) حالة طلب واحد

curl ".../wasselApi?action=status&external_id=ORD-1042" -H "x-store-key: مفتاح_متجرك"
يعيد: الحالة، الأجرة، المسافة، واسم السائق ورقمه بعد الاستلام.

٤) كل طلبات المتجر

curl ".../wasselApi?action=orders&limit=50" -H "x-store-key: مفتاح_متجرك"

٥) إلغاء طلب

curl -X POST ".../wasselApi?action=cancel" \
  -H "content-type: application/json" \
  -H "x-store-key: مفتاح_متجرك" \
  -d '{"external_id":"ORD-1042","reason":"العميل ألغى"}'

من JavaScript

const api = "https://base44.app/api/apps/6a74dc8dc6a9c9d7bc3ef6d1/functions/wasselApi";
const storeKey = process.env.WASSEL_STORE_KEY;

const res = await fetch(`${api}?action=publish`, {
  method: "POST",
  headers: { "content-type": "application/json", "x-store-key": storeKey },
  body: JSON.stringify({
    external_id: "ORD-1042",
    drop_lat: 15.5512, drop_lng: 32.6145,
    items_summary: "سلة خضار + أرز 5ك",
    customer_phone: "0922334455",
  }),
});
const data = await res.json();
if (!data.ok) console.error(data.code, data.message);
