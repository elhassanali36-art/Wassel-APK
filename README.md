# واصل — تطبيق السائق

## التثبيت

1. نزّل الملف من الرابط على الهاتف.
2. عند التحذير اختر «التنزيل على أي حال» ثم اسمح بـ«تثبيت من مصادر غير معروفة».
3. افتح «واصل» → أدخل بياناتك → أرسل التوثيق.

الأندرويد المطلوب ٧.٠ أو أحدث. التحديث فوق نسخة أقدم يعمل بدون فقدان البيانات.

## التوثيق المطلوب من السائق

- رخصة قيادة **سارية المفعول** (رقمها وتاريخ انتهائها).
- صورة الرخصة.
- صورة سيلفي وأنت تحمل الرخصة.

لا هوية ولا تعهّد ولا بيانات مركبة. الصور تبقى على جهازك ولا تُرسل إلا إذا فعّلت المزامنة.

## بعد التوثيق

- **السوق**: الطلبات المتاحة مرتّبة بالقرب، مع المسافة والزمن وشارة «موجّه إليك» إن عُرض عليك الطلب.
- **طلباتي**: الاستلام والتسليم وتحرير الطلب.
- **أرباحي**: تفصيل الدخل حسب فئة المتجر.
- **حسابي**: التوثيق، المزامنة الاختيارية، النسخ الاحتياطي.

المزامنة بين السائقين اختيارية: حسابي → «شبكة سوق السودان الكبير» → الصق رابط مشروع Supabase والمفتاح العام.
